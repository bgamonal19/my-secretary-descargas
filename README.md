# MY SECRETARY · Descargas

Instaladores de la app **MY SECRETARY / ONE ASYSTEN** (el código es privado).

| Dispositivo | Descarga |
|---|---|
| **Mac** (Apple Silicon e Intel) | [MY-SECRETARY-Mac.dmg](https://github.com/bgamonal19/my-secretary-descargas/releases/latest/download/MY-SECRETARY-Mac.dmg) |
| **Android** | [MY-SECRETARY.apk](https://github.com/bgamonal19/my-secretary-descargas/releases/latest/download/MY-SECRETARY.apk) |
| **iPhone / iPad** | Abre [one-assistant.vercel.app](https://one-assistant.vercel.app) en **Safari** → botón **Compartir** → **Añadir a pantalla de inicio** |

### Mac: la primera vez
macOS avisa porque la app no viene de la App Store. Abre el `.dmg`, arrastra MY SECRETARY a **Aplicaciones**, ábrela y, si sale el aviso, ve a **Ajustes del Sistema → Privacidad y seguridad → «Abrir igualmente»**.

### Android: la primera vez
Al abrir el `.apk`, Android pide permitir **«Instalar apps desconocidas»** para el navegador. Después, la app se actualiza sola.
